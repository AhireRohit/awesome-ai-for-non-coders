# Contributing

Thanks for helping! First-timers are very welcome.

## Add a resource (easiest way)
1. Open [README.md](README.md) and click the ✏️ pencil icon.
2. Add your link in the right section, in this format:
   `- [Name](https://link) - Short description ending with a period.`
3. Click **Propose changes** → **Create pull request**.

## Rules
- One resource per pull request.
- It must be useful for non-technical people.
- Free or has a free plan preferred. Mark paid-only tools with `(Paid)`.
- No affiliate or referral links. No duplicates.
- Keep descriptions short and simple.

## Other ways to help
- Fix broken links or typos.
- Add a new starter prompt.
- Translate the README (create `README-<language>.md`).
